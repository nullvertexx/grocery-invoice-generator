# Grocery Shop Invoice Generator

A fast, responsive Next.js invoice app for local grocery shops. It supports editable shop settings, customer/product memory, instant totals, print-ready invoices, PDF export through the browser print dialog, dark mode, and offline caching after the first visit.

## Run

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Verify

```bash
pnpm typecheck
pnpm lint
pnpm build
```
